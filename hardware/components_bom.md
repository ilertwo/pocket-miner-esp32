# Bill of Materials (BOM) — Pocket Miner ESP32

У цьому документі зібрано перелік усіх апаратних компонентів, необхідних для збірки портативної консолі.

## Основна електроніка

| Компонент | Характеристики / Модель | К-ть | Примітки та підключення |
| :--- | :--- | :---: | :--- |
| **Мікроконтролер** | ESP32-S3 DevKitC (ESP32-S3-WROOM-1-N16R8) | 1 | 16 MB Flash, 8 MB PSRAM. 2x Type-C. Головна плата. |
| **OLED Дисплей** | 0.96" I2C OLED (128x64), драйвер SSD1306 | 1 | I2C шина. **SDA** ➔ GPIO 8, **SCL** ➔ GPIO 9 |
| **Аналоговий джойстик** | Модуль джойстика XY (наприклад, KY-023) | 1 | Живлення: 3.3V. **VRX** ➔ GPIO 4, **VRY** ➔ GPIO 5 |
| **Тактові кнопки** | 12x12 мм або 6x6 мм (з ковпачками) | 2 | "Стрибок" ➔ GPIO 15, "Дія" ➔ GPIO 16. Резистори не потрібні (використовується `INPUT_PULLUP`). |
| **П'єзодинамік** | Пасивний (Passive Buzzer) | 1 | Для генерації 8-бітних звуків через `tone()`. Сигнал ➔ GPIO 7 |

## Деталі для прототипування та збірки

| Компонент | Призначення | К-ть | Примітки |
| :--- | :--- | :---: | :--- |
| **Макетна плата (Breadboard)** | Тестування схеми без пайки | 1-2 | Стандартна плата на 400 або 830 точок. |
| **З'єднувальні дроти (Dupont)** | Комутація компонентів | 1 набір | Тато-Тато (M-M) для макетки, Мама-Мама (F-F) для готового пристрою. |
| **Макетна плата (Perfboard)** | Фінальна пайка схеми (опціонально) | 1 | Якщо пристрій збирається не на кастомній друкованій платі (PCB). |
| **Pin Headers** | Підключення екрана та модулів | за потреби | Кроком 2.54 мм. |
| **Пластик для 3D-друку** | Виготовлення корпусу | ~50 г | PLA, PETG або ABS. |
| **Гвинти кріплення** | Фіксація плати та корпусу | 4-8 | M2 або M3 (залежить від дизайну корпусу). |

## Інструменти
* Паяльник (з тонким жалом для виводів ESP32-S3) та припій.
* 3D-принтер (для друку корпусу).
* Кабель USB Type-C (з підтримкою передачі даних) для прошивки мікроконтролера.
